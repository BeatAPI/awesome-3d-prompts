# Contributing

Submit one case per pull request. A case is eligible only when all four facts are public and reviewable:

1. The source explicitly names the model.
2. The exact prompt or agent instruction is copyable from the creator’s post, thread, repository, or official showcase.
3. A visible result is attached or linked.
4. The creator/source attribution is clear.

Do not reconstruct a missing prompt and label it exact. A derived prompt is accepted only with retained local run evidence and must be labeled `derived`. Do not remove watermarks or upload third-party media. Use the issue template for corrections or rights requests.

Run `npm run check` before proposing a change. Generated README and detail pages must be regenerated from `data/prompts.json`.
