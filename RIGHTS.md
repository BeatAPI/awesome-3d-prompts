# Provenance and rights

This repository is an attribution-first research index, not a relicensing archive.

- Prompts and agent instructions are quoted from the linked public source and attributed to the named creator. Their original rights remain with that creator.
- Preview URLs point to the original public host. This draft does not bundle third-party media or claim redistribution permission.
- A `review-required` status means publication and media redistribution have not been cleared.
- Model attribution records what the public source claims. It is not an independent benchmark result or a guarantee that the output can be reproduced.
- If you own an entry and want it corrected or removed, open a provenance issue with the source URL and requested change.

The MIT license applies only to original scripts, validation logic, templates, and editorial structure created for this repository.
